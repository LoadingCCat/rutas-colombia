# Sistema de Rutas y Conexiones entre Ciudades de Colombia

## Integrantes
- Julián Camilo Aya Mendoza

## Objetivo
Construir un programa en consola que represente la red de carreteras de Colombia: cada ciudad
será un vértice y cada carretera una arista con su distancia. Con esto se podrán registrar
conexiones, recorrer el mapa y, en las siguientes entregas, encontrar el camino más corto
entre dos ciudades usando Dijkstra.

## Lenguaje utilizado
C++ (compilador g++)
